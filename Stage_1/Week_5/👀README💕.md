# Stage 1 · Week 5

## Cumulative Challenge Architecture
Week 5 is the capstone for Stage 1. The architecture combines everything you learned:

- **Structured input handling** from Week 1
- **Collections and persistence** from Week 2
- **Object‑oriented design** from Week 3
- **Abstraction/interfaces** from Week 4

The goal is to build a cohesive program that is maintainable and extensible, rather than a one‑off script.

## Architecture Pattern
1. **Domain model** — define classes that represent the problem.
2. **Workflow** — a menu loop that drives user actions.
3. **Processing logic** — business rules inside domain classes.
4. **Storage layer** — optional read/write to files.
5. **Presentation** — consistent, formatted output.
