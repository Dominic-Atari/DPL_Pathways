# Stage 2 · Week 5

## Capstone Architecture (Planned)
Week 5 serves as the capstone of Stage 2. The expectation is a complete application pipeline: from user interaction to data processing to UI rendering, with clear separation of responsibilities.

## Suggested Architecture Outline
1. **User journeys** — define the core flows and screens.
2. **Data flow** — inputs, API responses, and derived state.
3. **Modules/components** — distinct responsibilities per file.
4. **Error handling** — graceful failures and fallbacks.
5. **Build/run process** — how the project compiles and launches.

## Teaching Goal
Explain the overall system design so a new developer can extend it confidently.
