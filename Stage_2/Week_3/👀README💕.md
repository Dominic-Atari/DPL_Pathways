# Stage 2 · Week 3

## Architecture Expansion (Planned)
Week 3 is reserved for the next layer of web‑app architecture. When projects are added, this README should teach how **state**, **data flow**, and **UI rendering** connect into a maintainable structure.

## Suggested Architecture Outline
1. **UI layer** — HTML/CSS or framework templates.
2. **State management** — in‑memory models or framework state.
3. **Data access** — API or storage abstraction.
4. **Rendering** — view updates after state changes.
5. **User flow** — events drive transitions between states.

## Teaching Goal
Explain not just what the program does, but how it is structured so new features can be added without rewriting existing logic.
